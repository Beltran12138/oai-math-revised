- [Mohit Daga, *Thin Trees via k-Respecting Cut Identities*](https://arxiv.org/abs/2510.12050) (arXiv:2510.12050, 14 October 2025). Computes exact thinness certificates for a given spanning tree, including for cuts crossing the tree in a bounded number of edges, and gives O(1/λ)-type certificates for planar graphs, so it bears on checking the all-cut bound of Theorem 1.1 for concrete trees.
